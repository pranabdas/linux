VI/VIM is a simple and powerful editor. If you are accessing a remote
workstation or cluster where you don't have the option to launch graphical
programs, VIM is a great option. Almost any Linux or UNIX system has VI
preinstalled. Recent OS releases will likely have VIM (**V**i **IM**proved)
instead of the classic VI editor. You can check the version by:

```bash
vi --version
```

If it is not installed, you can use a package manager:

```bash
# Ubuntu / Debian
apt install vim
```

Open or create a file to read and/or write:

```bash
vi file.txt
```


## Modes

VIM is a modal editor — understanding its modes is the key to using it
effectively.

### Normal (Read-only) Mode

This is the default mode when you open VIM. Press <kbd>Esc</kbd> at any time to
return to Normal mode. All keyboard shortcuts in the [Keyboard Shortcuts](
#keyboard-shortcuts) section apply here.

### Insert Mode

Press <kbd>i</kbd> to enter Insert mode. You will see `-- INSERT --` at the
bottom of the window. Other ways to enter Insert/editing mode:

| Key | Description |
| --- | ----------- |
| <kbd>i</kbd> | Insert text before the cursor |
| <kbd>a</kbd> | Append text after the cursor |
| <kbd>I</kbd> | Insert at the beginning of the current line |
| <kbd>A</kbd> | Append at the end of the current line |
| <kbd>o</kbd> | Open a new line below the cursor and enter Insert mode |
| <kbd>O</kbd> | Open a new line above the cursor and enter Insert mode |

While in Insert mode, the following shortcuts are available:

| Key binding | Description |
| ----------- | ----------- |
| <kbd>Ctrl</kbd>+<kbd>w</kbd> | Delete the word before the cursor |
| <kbd>Ctrl</kbd>+<kbd>u</kbd> | Delete from cursor to line beginning |
| <kbd>Ctrl</kbd>+<kbd>t</kbd> | Indent the current line |
| <kbd>Ctrl</kbd>+<kbd>d</kbd> | Outdent the current line |

### Replace Mode

Press <kbd>Shift</kbd>+<kbd>r</kbd> to enter Replace mode. You will see
`-- REPLACE --` at the bottom of the window. Characters you type overwrite
existing text.

### Visual Mode

Enter Visual mode from Normal mode using one of:

| Key | Description |
| --- | ----------- |
| <kbd>v</kbd> | Visual character mode |
| <kbd>V</kbd> | Visual line mode |
| <kbd>Ctrl</kbd>+<kbd>v</kbd> | Visual block mode |

Select text using the arrow keys or <kbd>j</kbd>/<kbd>k</kbd>. Once selected,
you can:

- Press <kbd>c</kbd> to clear the selected text and enter Insert mode.
- Press <kbd>d</kbd> to delete the selected text.
- Press <kbd>y</kbd> to yank (copy) the selected text.
- Press <kbd>p</kbd> to paste yanked text at another location in VIM.
- Press <kbd>"</kbd>+<kbd>y</kbd> (or <kbd>"</kbd><kbd>*</kbd><kbd>y</kbd>
  on macOS) to copy to the system clipboard, then paste in another program
  with <kbd>Ctrl</kbd>+<kbd>v</kbd> (or <kbd>Command</kbd>+<kbd>v</kbd>
  on macOS).

**Deleting multiple lines:**
Enter Visual line mode with <kbd>Shift</kbd>+<kbd>v</kbd>, select lines with
arrow keys or <kbd>j</kbd>/<kbd>k</kbd>, then press <kbd>d</kbd> to delete or
<kbd>c</kbd> to clear and enter Insert mode.

**Commenting multiple lines:**

1. Enter Visual block mode: <kbd>Ctrl</kbd>+<kbd>v</kbd>
2. Select the first column of the target lines using arrow keys.
3. Enter Insert mode: <kbd>Shift</kbd>+<kbd>i</kbd>
4. Type the comment character, e.g., `#`
5. Press <kbd>Esc</kbd>.

**Un-commenting multiple lines:**

1. Enter Visual block mode: <kbd>Ctrl</kbd>+<kbd>v</kbd>
2. Select the comment character(s) across lines using arrow keys.
3. Press <kbd>x</kbd> to delete the selection, then <kbd>Esc</kbd>.


## Saving and Exiting

First return to Normal mode with <kbd>Esc</kbd>, then use any of the following:

| Command | Description |
| ------- | ----------- |
| `:w`    | Save the file |
| `:q`    | Quit VIM |
| `:wq`   | Save and quit (also <kbd>Shift</kbd>+<kbd>Z</kbd><kbd>Z</kbd>) |
| `:q!`   | Quit without saving (also <kbd>Shift</kbd>+<kbd>Z</kbd><kbd>Q</kbd>) |
| `:w !sudo tee %` | Save a file opened without root privileges |


## Keyboard Shortcuts

All shortcuts below apply in **Normal mode**. Press <kbd>Esc</kbd> to ensure you
are in Normal mode before using them.

### Navigation

| Key binding | Description |
| ----------- | ----------- |
| <kbd>g</kbd><kbd>g</kbd> | Go to the beginning of the file |
| <kbd>G</kbd> | Go to the end of the file |
| <kbd>5</kbd><kbd>G</kbd> | Go to line 5 (replace 5 with any line number) |
| <kbd>5</kbd><kbd>H</kbd> | Move to 5 lines below the top of the screen |
| <kbd>3</kbd><kbd>L</kbd> | Move to 3 lines above the bottom of the screen |
| <kbd>Ctrl</kbd>+<kbd>f</kbd> | Scroll forward one page |
| <kbd>Ctrl</kbd>+<kbd>b</kbd> | Scroll backward one page |
| <kbd>$</kbd> | Go to the end of the line |
| <kbd>0</kbd> | Go to the beginning of the line |
| <kbd>w</kbd> | Move one word forward |
| <kbd>b</kbd> | Move one word backward |

### Editing

| Key binding | Description |
| ----------- | ----------- |
| <kbd>d</kbd><kbd>b</kbd> | Delete one word backward |
| <kbd>d</kbd><kbd>w</kbd> | Delete one word forward |
| <kbd>d</kbd><kbd>$</kbd> / <kbd>D</kbd> | Delete to the end of the line |
| <kbd>d</kbd><kbd>0</kbd> | Delete to the beginning of the line |
| <kbd>d</kbd><kbd>d</kbd> | Delete the whole line |
| <kbd>5</kbd><kbd>d</kbd><kbd>d</kbd> | Delete 5 lines below the cursor |
| <kbd>d</kbd><kbd>G</kbd> | Delete all lines from cursor to end of file |
| <kbd>d</kbd><kbd>g</kbd><kbd>g</kbd> | Delete all lines from cursor to beginning of file |
| <kbd>c</kbd><kbd>c</kbd> | Clear the whole line and enter Insert mode |
| <kbd>c</kbd><kbd>G</kbd> | Clear all lines below cursor and enter Insert mode |
| <kbd>c</kbd><kbd>g</kbd><kbd>g</kbd> | Clear all lines above cursor and enter Insert mode |
| <kbd>u</kbd> | Undo (also `:u`; use `:2u` to undo twice) |
| <kbd>U</kbd> | Undo all line changes (itself undoable with <kbd>u</kbd>) |
| <kbd>Ctrl</kbd>+<kbd>r</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>l</kbd> | Redraw/reload the screen |
| <kbd>.</kbd> | Repeat the last command |

### Moving Lines

To move a line up or down, use these key combinations in Normal mode:

- **Move line up:** <kbd>d</kbd><kbd>d</kbd> + <kbd>k</kbd> + <kbd>P</kbd>
- **Move line down:** <kbd>d</kbd><kbd>d</kbd> + <kbd>j</kbd> + <kbd>P</kbd>

How it works: <kbd>d</kbd><kbd>d</kbd> deletes the current line into the default
register; <kbd>k</kbd> (up) or <kbd>j</kbd> (down) moves the cursor;
<kbd>P</kbd> pastes the line above the new cursor position.


## Searching

Type <kbd>/</kbd> followed by the phrase you are looking for and press
<kbd>Enter</kbd>. Press <kbd>n</kbd> to jump to the next match, or
<kbd>Shift</kbd>+<kbd>n</kbd> to go to the previous match. Search backwards
by starting with <kbd>?</kbd> instead of <kbd>/</kbd>.


## Command-line Options and Settings

### Line Numbers and Display

| Command     | Description       |
| ----------- | ----------------- |
| `:set nu`   | Show line numbers |
| `:set nonu` | Hide line numbers |

### Spell Checking

| Command                              | Description                         |
| ------------------------------------ | ----------------------------------- |
| `:set spell`                         | Enable spell checking               |
| `:set nospell`                       | Disable spell checking              |
| `:set spellfile=~/.vim/en.utf-8.add` | Set a custom user spell file        |
| <kbd>z</kbd><kbd>=</kbd>             | Show spelling suggestions           |
| <kbd>z</kbd><kbd>g</kbd>             | Add word under cursor to dictionary |
| <kbd>z</kbd><kbd>u</kbd><kbd>g</kbd> | Remove word from the dictionary     |

Browse files and folders using VIM's built-in file explorer:


### Comparing Files

Open two files side-by-side to compare differences:

```bash
vi -d file.txt file_edit.txt
```

## vimrc

Customize your editor by creating a `~/.vimrc` file. Below is a sample
configuration with commonly used settings:

```vim
syntax on
set tabstop=4
set ruler
colorscheme darkblue
set textwidth=80
set cc=81
set autoindent
set spell
hi SpellBad ctermbg=Yellow
hi SpellBad ctermfg=DarkRed
set spellfile=~/.vim/en.utf-8.add

" Syntax highlight for custom file types
au BufRead,BufNewFile *.in  set filetype=fortran
au BufRead,BufNewFile *.out set filetype=fortran
au BufRead,BufNewFile matplotlibrc set filetype=python

set hlsearch
hi Search ctermbg=LightBlue
hi Search ctermfg=black
```

### Tabs and Indentation

Convert tabs to spaces by adding the following to your `.vimrc`:

```vim
set tabstop=2 shiftwidth=2 expandtab
```

Then convert any existing tabs in an open file with:

```vim
:retab
```

To set a different tab width for a specific file type:

```vim
aug python
    " ftype/python.vim overwrites this
    au FileType python setlocal ts=4 sts=4 sw=4 noexpandtab
aug end
```

## Plugins

VIM's functionality can be extended with plugins. The popular plugin manager
**vim-plug** makes installation and management straightforward.

### Installing vim-plug

```bash
curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

### Adding Plugins

Add a `plug` block to your `.vimrc`:

```vim
call plug#begin('~/.vim/plugged')
    Plug 'junegunn/goyo.vim'
call plug#end()
```

Save the file with `:w`, then install the listed plugins:

```vim
:PlugInstall
```

### Customizing a Plugin

You can modify or add settings to an installed plugin directly. For
example, to automatically activate **Limelight** alongside **Goyo**, open:

```bash
~/.vim/plugged/goyo.vim/autoload/goyo.vim
```

and add `Limelight` (along with any other settings such as `set spell`) at
the appropriate location in that file.
